# Legado

`cli/` guarda o Ink Manager original: um CLI de terminal em Java puro
(`MainMaster.java`) que gravava clientes e marcacoes em PostgreSQL via JDBC
(`lib/postgresql-*.jar`).

Ele **nao faz parte do build nem do deploy** e nao e mantido. Fica aqui so como
registro historico. A aplicacao ativa e o [ink-manager-api](../ink-manager-api/README.md).
Nao use este codigo como referencia para regras de negocio atuais.
