## Historico

A pasta [historico/](historico/) guarda relatorios de validacao e checklists datados
(17 a 21/10/2026), anteriores a implantacao na VPS e a troca do Mercado Pago pelo
Stripe. Eles registram o que foi verificado naquela data e **nao descrevem o estado
atual**. Um relatorio de validacao novo entra no historico com a data no nome.
