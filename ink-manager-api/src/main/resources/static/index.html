DÚVIDAS FREQUENTES

Tudo claro antes de começar.

Preciso de cartão de crédito para testar?

Não. Você pode criar sua conta sem cadastrar cartão e usar o prazo de avaliação disponível para ela.

Meus clientes precisam criar uma conta?

Não. Seus clientes abrem o link público, escolhem serviço e horário disponíveis e informam os dados solicitados na reserva.

Como funcionam os lembretes automáticos?

Quando o cliente informa o e-mail na reserva, ele recebe a confirmação na hora e lembretes 24 horas e 2 horas antes do atendimento, com links para confirmar, reagendar ou cancelar.

Posso configurar meus serviços e horários?

Sim. Você configura serviços, preços, duração e disponibilidade da equipe na área interna.

O que acontece depois dos 14 dias grátis?

Você passa a pagar R$ 29,90 por mês, por Pix ou cartão. O Pix é um pagamento mensal avulso, sem renovação automática; o cartão é uma assinatura mensal recorrente. Sem pagamento, novas gravações ficam bloqueadas, mas os dados continuam disponíveis para consulta.

O Pix renova automaticamente?

Não. O Pix é um pagamento mensal avulso e precisa ser pago novamente a cada ciclo. O cartão funciona como uma assinatura recorrente.

Como funciona a lista de espera?

O Marcaê oferece por e-mail a vaga aberta por um cancelamento a quem está aguardando, com prazo para aceitar, conforme a configuração da lista de espera.

Posso cancelar quando quiser?

Sim. No cartão, você cancela a renovação automática na tela Assinatura do painel e o acesso continua até o fim do período já pago. No Pix não há renovação: basta não pagar o mês seguinte.

Os dados dos meus clientes ficam seguros?

Sim. Todo o site usa conexão criptografada (HTTPS), as senhas são guardadas com hash e os dados de cada negócio ficam separados dos demais. O banco de dados fica em um servidor no Brasil e as cópias de segurança são criptografadas. Os detalhes estão na Política de privacidade.

Posso levar meus dados se sair do Marcaê?

Sim, mediante pedido. O painel ainda não tem um botão de exportação; pela LGPD, o responsável pelo negócio pode pedir acesso e portabilidade dos dados pelo contato indicado na Política de privacidade.
